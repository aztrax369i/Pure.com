# Pure.com
E-commerce orientado a la confección, personalización y venta de uniformes de trabajo: pijamas quirúrgicas para personal de salud, de belleza y estudiantes.

Integración del equipo:

Aranza Islas: Liderazgo de Frontend - UI/UX. Maqueta las vistas en HTML5 y CSS3 (Bootstrap), garantizando que la plataforma sea de fácil navegación y cumpla con el diseño responsivo.
Alexander Olivieri: Lógica de Frontend. Desarrolla el comportamiento dinámico con JavaScript (ECMAScript 6), enfocándose en los temporizadores de las subastas y la validación de formularios en el cliente.
